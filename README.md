# Habit Tracker

A simple MERN stack Habit Tracker application that helps users manage their daily habits.

 Features

* Add habits
* View habits
* Edit habits
* Delete habits
* Mark habits as completed

 Tech Stack

* React.js
* Node.js
* Express.js
* MongoDB
* Mongoose

API

* `POST /api/habits` - Create habit
* `GET /api/habits` - Get all habits
* `PUT /api/habits/:id` - Update habit
* `DELETE /api/habits/:id` - Delete habit
